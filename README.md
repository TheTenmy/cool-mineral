# Cool Mineral

**RU** · [EN](#english)

Концепт сайта-справочной для сети недорогих магазинов одежды: газетная стилистика, продающая главная, два языка и мобильная версия. Компания, люди и отзывы выдуманы — это проект для портфолио. Как он делался, рассказано на странице [case.html](case.html).

Чтобы посмотреть сайт, откройте `index.html` в браузере. Сервер и сборка не нужны.

Русский текст написан прямо в HTML, английский лежит в `assets/js/lang/en.js`. Товары описаны в `assets/js/catalog.js`.

Перед публикацией замените в `og:image` на всех страницах путь `assets/img/og-cover.jpg` на полный адрес сайта, иначе в соцсетях не будет картинки в превью ссылки.

Фото взяты с Unsplash

[RU](#cool-mineral) · **EN**

A help-desk website concept for an affordable clothing chain: newspaper-style design, a selling home page, two languages and a mobile version. The company, people and reviews are fictional — this is a portfolio project. The story behind it is on [case.html](case.html).

To view the site, open `index.html` in a browser. No server or build step needed.

Russian text lives in the HTML, English in `assets/js/lang/en.js`. Products are listed in `assets/js/catalog.js`.

Before publishing, replace `assets/img/og-cover.jpg` in `og:image` on every page with the full site URL, otherwise social networks won't show the link preview image.
